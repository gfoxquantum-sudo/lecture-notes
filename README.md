# 蛤說啥 Say What?

上課錄音 → 即時字幕 → 下課後一鍵整理成有結構的中英對照筆記。
手機、平板、電腦都能用（網頁 App，可以「加入主畫面」）。

網址：https://gfoxquantum-sudo.github.io/lecture-notes/

## 兩種方案

| | 免費版 | 進階版 |
|---|---|---|
| 費用 | NT$0 | 用多少付多少，一堂 90 分鐘課約 NT$20 |
| 即時字幕 | 瀏覽器內建辨識，一次一種語言 | Soniox：中英混講、每句即時翻譯 |
| 分辨教授／同學 | ✗ | ✓ |
| 整理筆記 | 在裝置上自動整理（找重點句、專有名詞、教授強調的地方） | Claude 讀完講義和逐字稿重新寫成筆記 |
| 中英對照 | 電腦版 Chrome 可用內建翻譯 | 所有裝置 |
| 需要 | 什麼都不用 | Soniox 和 Anthropic 金鑰（各自先儲值） |

第一次打開 App 會跳出方案比較，之後可以在「設定」或右上角的方案標籤切換。

## 筆記內容（兩種方案都有）
總覽（一句話重點、概要、學習目標、康乃爾筆記、待辦）、大綱（依時間分段、標出重點）、心智圖、專有名詞表、考試重點、課堂問答、自我測驗翻卡。可以切換 中／中英／EN，匯出 Markdown 或 PDF。

## 外觀
設定裡可以選 系統／淺色／深色、6 種主題色、開關動態效果。

## 隱私
錄音、逐字稿、講義、筆記、金鑰都只存在你的裝置上，不會同步到其他裝置；要在別台看，用匯出。
免費版的語音辨識由瀏覽器提供（Chrome 會把聲音送到 Google 辨識，Safari 由 Apple 處理）。

## 更新網站
改過的檔案拖到 GitHub repo 的「Add file → Upload files」覆蓋即可，1–2 分鐘後網站會更新。
