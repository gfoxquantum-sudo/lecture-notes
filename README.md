# 課堂筆記

上課錄音 → 即時字幕（分辨教授／同學、中英對照）→ 下課後一鍵整理成有結構的中英對照筆記。
手機、平板、電腦都能用（網頁 App，可以「加入主畫面」）。

## 功能
- **即時字幕**：教授說的話即時出現，中英混講也能辨識，每句旁邊附翻譯。
- **講者辨識**：自動分出不同說話者，講最多的人判定為教授（★）；點名字可以改名或改設誰是教授。
- **上傳講義**：PDF、PPTX、DOCX、圖片、文字檔，整理筆記時一起讀，用來校正專有名詞。
- **筆記**（全部中英對照，可切換 中／中英／EN）：
  - 總覽：一句話重點、概要、學習目標、康乃爾筆記（提示問題＋筆記＋總結）、待辦事項
  - 大綱：依上課時間分段，教授強調的地方標「重點」
  - 心智圖、專有名詞表、比較表格
  - 考試重點（附判斷依據）、課堂問答（同學提問）、自我測驗卡
- **回放**：點逐字稿任一句，跳到那段錄音。
- **匯出**：Markdown、列印／存 PDF、下載錄音檔。

## 需要的金鑰（在 App 的「設定」填）
| 用途 | 服務 | 沒有的話 |
|---|---|---|
| 即時字幕、講者辨識、即時翻譯 | [Soniox](https://console.soniox.com) | 用瀏覽器內建免費辨識：不分講者、沒即時翻譯 |
| 整理筆記、補翻譯 | [Anthropic](https://console.anthropic.com)（Claude Opus 5.5） | 不能產生筆記 |

兩個都是用多少付多少。金鑰只存在你那台裝置的瀏覽器，不會進到程式碼或網站上。

## 放上網路（手機、平板才能用）
麥克風只能在 https 網址下使用，所以要把這個資料夾放到免費的靜態網站空間，例如：
- **Netlify**：登入 app.netlify.com → Add new site → Deploy manually → 把整個 `lecture-notes` 資料夾拖進去。
- **GitHub Pages**：建一個 repo，上傳這些檔案，Settings → Pages 開啟。

拿到網址後，在每台裝置用瀏覽器打開 → 分享 → 加入主畫面。

## 注意
- 資料（錄音、逐字稿、筆記）存在各自裝置上，**不會自動同步**；要在別台看，用匯出。
- iPhone／iPad：螢幕鎖定或切到別的 App 時錄音會中斷，上課時讓 App 留在前景（App 會盡量保持螢幕亮著）。
- 教授的聲音越清楚越準，裝置盡量放近講台。
